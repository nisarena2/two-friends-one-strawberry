# Two Friends, One Strawberry

A warm storybook illustration of a ginger kitten and a small yellow duckling laughing together while sharing one big red strawberry on a sunny windowsill. Golden afternoon light pours in, a sunflower blooms in a pot beside them, and the whole scene is full of simple, cheerful friendship.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This copies `entry.png` into the output directory.

The image is 1024x1024 and under 1 MiB.
